# Licensing and attribution status

This repository currently contains original planning material, original design specifications, a design specimen, and a user-supplied reference document. No project-wide software license has been selected. Do not infer a redistribution grant from repository visibility.

IBM Carbon and Google Material Design are reference systems, not project sponsors. Cloudy Workspace's palette, spacing decisions, screen arrangements, and component rules are a proposed adaptation. Third-party names, marks, documentation, fonts, icons, and code retain their respective rights and licenses.

Official sources are linked and briefly summarized rather than mirrored. The supplied plan is preserved for project provenance. Before public distribution, resolve its publication status and select the project's software/documentation license. See [dependency and licensing review](docs/03-platform/dependency-licensing.md).
