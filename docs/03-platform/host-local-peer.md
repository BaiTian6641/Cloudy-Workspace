## Operation and caller ownership

The caller supplies an already connected UNIX stream connection and a trusted expected effective UID. The expected UID is policy from the owning caller; accepting a peer-supplied number would defeat that check. Zero has no implicit user mapping or bypass.

`RequireUID` borrows the connection through `UnixConn.SyscallConn` and inspects the descriptor only inside `RawConn.Control`. It checks `SO_TYPE == SOCK_STREAM`, a successful `Getpeername` with `SockaddrUnix`, then queries the OS-specific maintained credential wrapper. Linux uses `GetsockoptUcred(fd, SOL_SOCKET, SO_PEERCRED)` and exact UID equality; Darwin uses `GetsockoptXucred(fd, SOL_LOCAL, LOCAL_PEERCRED)` with external layout version0 and exact UID equality. Linux Ucred has no Darwin version field and none is fabricated. Nil/closed connections, invalid socket preconditions, query errors, missing credentials, invalid Darwin credential version and UID mismatch return fixed safe errors. The raw OS cause remains private without `Unwrap`; paths, IDs or endpoint data are not interpolated into error text.

The function does not read/write bytes, change deadlines, duplicate/close descriptors or take connection ownership. The caller still owns the connection on success and failure. `RawConn.Control` protects the borrowed descriptor's callback lifetime; retaining its integer for later work is prohibited. [Go1.27.2 UnixConn.SyscallConn](https://pkg.go.dev/net@go1.27.2#UnixConn.SyscallConn), [RawConn.Control](https://pkg.go.dev/syscall@go1.27.2#RawConn).

## Exact trust boundary

A successful result establishes one kernel peer-credential observation and equality with the caller's expected effective UID. It does not identify a particular same-user program, code signature, login/GUI session, current console owner, consent, remote paired identity or authority for an operation. Connection credentials are not a continuously refreshed process identity. Linux SO_PEERCRED reflects the credential snapshot at connect/listen/socketpair time. Its numeric identity must be interpreted within the caller's trusted namespace policy, not treated as a universal host account identifier. [Linux unix(7)](https://man7.org/linux/man-pages/man7/unix.7.html), [user_namespaces(7)](https://man7.org/linux/man-pages/man7/user_namespaces.7.html). Descriptor transfer and hostile same-user behavior need separate protocol/deployment policy; this function alone does not resolve them. No GID, group list, PID or process inventory is exposed. [Apple getpeereid reference](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/getpeereid.3.html).

Do not use a matching UID to enable remote jobs or advertise a working session adapter. macOS descendant ownership remains unimplemented in the [local-jobs contract](host-local-jobs.md). Process groups, helper presence and this socket check do not qualify job retirement.
