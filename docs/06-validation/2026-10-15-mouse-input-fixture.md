A last-snapshot-to-dispatch race remains.

One pointer uses `SOURCE_MOUSE` and `TOOL_TYPE_MOUSE`; DOWN carries `BUTTON_PRIMARY`. The helper emits down/up framework acceptance and uptime/elapsed observations; its final success string establishes only that both injection calls returned true.
