[NetworkEvidenceStore.java](../../qualification/probes/native-stream/android/app/src/main/java/dev/cloudy/qualification/stream/NetworkEvidenceStore.java) and [NetworkJournalPolicy.java](../../qualification/probes/native-stream/android/app/src/main/java/dev/cloudy/qualification/stream/NetworkJournalPolicy.java) cross-check both pairing and playback before either network action. Successful local reconciliation cannot certify host shutdown, enrollment removal or native runtime behavior.

The UI reports actual controller counters separately: decode-unit submissions, output buffers released for rendering and frame-render callbacks.
