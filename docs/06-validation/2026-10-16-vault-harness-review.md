Reusing each consumed Save/Use grant must yield AUTH_REQUIRED; Use replay must invoke zero consumers. It records operation/process IDs, monotonic times, bounded result codes, counters, comparison boolean and actual key-info fields; no endpoint/account body, password, ciphertext, AAD, raw exception or secret hash. It is stored in owning-app no-backup storage, with AtomicFile readback. Receipt failure makes that process unavailable; it does not silently reset evidence. Activity stop cancels authority and pending payloads. A ten-minute deadline ends the Activity without automatic deletion; an OS stall may delay handler execution.

One process-wide metadata owner on the single worker now receives all appends, without storing grants, callbacks or payloads. A failed receipt latches unavailable; the cleanup worker checks that latch before mutation. A revoked generation no longer leaves a returning Activity stuck busy after a worker exception. Parent reviewed the corrected source and explicit debug-only wiring.
