# Qualification workspace

Use [inventory.example.json](inventory.example.json) as a non-secret field template, then create the ignored `inventory.local.json` with real equipment. Public evidence belongs in [results](results/README.md), linked from the stage and [compatibility matrix](../docs/06-validation/compatibility-matrix.md).

No physical qualification is claimed by this initial repository. Read the [validation strategy](../docs/06-validation/strategy.md) before running experiments. Keep raw/private device identities and logs out of Git.
