Run `.cache/native-vnc/adapter/entry-02/receipt.json` records the actual source, compiler evidence, prepared files, nine JNI exports and ELF. The JNI library needs only accepted SSL/crypto plus Android libc/libdl/libm/libz, with AArch64 SONAME and 16384-byte minimum load alignment. This is not APK zip alignment or Android loader proof. Owned C11 compiled with `-Wall -Wextra -Wpedantic -Werror`; linking rejects undefined symbols and hides embedded archive exports. The Java bridge compiled with `--release17 -Xlint:all -Werror`. Existing upstream deprecation warnings remain visible in the separately compiled patched client; no suppression was added.

The approved narrow patch admits only **VeNCrypt19 / X509Plain262**, including a top-level allowlist check on RFB3.3, and filters subtypes before selection. The actual peer leaf DER is checked unconditionally after TLS handshake and before credentials: exact configured SHA256, complete DER parsing and validity times, bound to the immutable numeric endpoint/port/profile. TLS minimum is1.2 and renegotiation is disabled. No plaintext, anonymous, None, ordinary VNC-password or CA-validity shortcut is an authentication fallback. These are implemented source policies whose real handshake/negative-negotiation behavior still needs qualification.

Native ownership is one process instance and one worker, a typed 256-entry input queue, explicit cancel/join/free and bounded copied framebuffer callbacks. A successful queue return is admission; the asynchronous callback reports the actual upstream send return, not host receipt. Cancellation invalidates admission, interrupts a mutex-published socket and leaves cleanup to the owner; join timeout retains ownership. The initial connect is bounded to 3 seconds before socket publication. Deadline checks are cooperative at I/O/poll boundaries and cannot force a blocked Java Sink or arbitrary decoder CPU work to return. The UI must use promptly returning callbacks and free only after join. There is no UI, clipboard/drive/USB forwarding, credential vault or relative-input emulation in this increment.

Three focused tests passed. One strictly compiled and executed the actual authored C policy against host OpenSSL under ASan/UBSan, performing **32 checks** for valid/wrong pin, expired/not-yet-valid leaf, malformed/truncated/trailing/oversized DER, numeric endpoints, UTF8, geometry and wiping. Two test changed-input/output rejection. These do not simulate remote protocol responses, exercise an actual TLS handshake, or qualify Android JNI/queue/callback behavior. Offline verification also passed with a nonexistent SDK path. Targeted Ruff and Python AST 26 passed; private check receipts/output hashes are bound by the public manifest. The accepted 27 host advisory cases were carried forward without rerun.

Initial adapter **entry-01** rebuilt the patched static client but strict owned JNI compilation stopped on the OpenSSL4-deprecated `X509_cmp_current_time`. Its exact inputs, failed step receipt/log and failure record are retained. Entry-02 uses supported `ASN1_TIME_cmp_time_t`, rejects its parse-error code, and passes without warning suppression. The parent owns final shared validation and integration acceptance; no worker device, listener, network connection, Gradle, system-install or Git operation occurred.

Next gates are an actual Android load/lifetime probe, protected real-server handshake and rejection cases, frame/input/cancellation/recovery observations and the eventual UI.
