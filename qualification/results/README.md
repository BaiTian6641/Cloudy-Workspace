# Run evidence

This directory intentionally contains no fabricated run results. For a real experiment, use `<stage-id>/<run-id>/` with a run report based on the [template](../../docs/06-validation/templates/run.md), sanitized artifacts, and hashes.

Keep raw/private material in the ignored `private/` directory or another controlled location. A support-matrix row links to an actual run and exact version/topology, not to this placeholder.
