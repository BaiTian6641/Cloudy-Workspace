# Diagnostics and accounting

**State:** planned module boundary; no application/library implementation yet. **Delivery stages:** P1-S3, P5-S4, P6.

## Responsibility

Bounded redacted structured logs, actual backend error chains, context/version capture, counter provenance, and export preview.

## Boundary

No terminal transcripts, tokens, keys, clipboard contents, or OAuth caches by default. Measured payload/wire/estimates remain separate.

## First implementation work

Provide actionable errors and honest unknown states; synthetic CI output is not physical capture/permission proof.
